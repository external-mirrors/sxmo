# Installation Guide

To check if your device can run Sxmo, first carefully consult the [nura device
page](https://wiki.nura.eco/wiki/Devices) and check with users.

The easiest way to then get started using S*x*mo is to install from [an image
provided by nura](https://images.nura.eco/bpo/).  These images
are generated on a weekly basis and offer Sxmo as one of the options. They are
based on [nura](http://nura.eco), which is in turn based on
[Alpine Linux](https://alpinelinux.org). You can also create these images
yourself, locally, using `pmbootstrap`. This offers some advantages as you can
customize more.

Sxmo comes in two flavours, one using Xorg with dwm (sometimes named
`sxmo-de-dwm`), another using Wayland with sway (sometimes named `sxmo-de-sway`
or even `swmo`). The latter is recommended and likely the default if your
device supports it. 

The installation instructions may differ corresponding to the device you are
using, please see the [the nura installation page](https://nura.eco/install/).

## Other distributions

If you prefer another Linux Distribution such as [mobian](https://mobian.org)
(debian-based) or [Arch Linux ARM for Pinephone/Pro](https://github.com/dreemurrs-embedded/Pine64-Arch) then follow the
instructions from there. 

Note that Sxmo packaging for other distributions is handled by other parties,
we ourselves package for nura.
